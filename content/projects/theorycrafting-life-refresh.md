Theorycrafting.life is being rebuilt as a living field notebook for leadership, systems thinking, creative work, and the experiments that connect them.

## The brief

The site needed to become easier to return to after a quiet year. That meant keeping the dark, forge-inspired character while giving the structure more room to breathe:

- make the main paths obvious;
- keep pages readable on a phone;
- make business contact cards simple and reusable; and
- create a system that stays easy to change.

## What is in place

The refreshed site now has a clearer shell, a more focused About page, reusable contact-card templates, and separate spaces for Workshop notes, Forge experiments, Journal entries, and active Projects.

The project is intentionally light. Hugo handles the content, Cloudflare Pages handles deployment, and the site does not need a database, account system, subscription layer, or heavy front-end framework to remain useful.

## Design constraints

The work should stay:

- **Readable:** dark surfaces, restrained gold accents, and comfortable text measure.
- **Accessible:** visible focus states, semantic structure, reduced-motion support, and useful links.
- **Maintainable:** content lives in Markdown and new project entries use the same shared layout.
- **Honest:** build notes should show what exists, what is still changing, and what remains untested.

## Next iteration

The next project entries will document practical tools, experiments, and lessons that are useful beyond a single moment. The goal is not to make the site look finished. It is to make the next useful change easier to begin.
